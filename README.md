# TurnoBot · maqueta alternativa

Segunda exploración visual del panel de reservas. Usa una paleta violeta y azul, navegación clara y una **agenda semanal en grilla con los rangos horarios a la izquierda**. La vista diaria conserva las columnas de profesionales y también muestra los rangos a la izquierda.

Esta versión está en un repositorio independiente de la [primera maqueta](https://juansiniguez.github.io/TurnoBot-Panel-Demo/). Podés compararlas sin que una sustituya a la otra.

## Publicación

En **Settings → Pages → Build and deployment**, seleccionar **Deploy from a branch**, rama **main** y carpeta **/(root)**. No se necesita compilación.

## Alcance

Los nombres y turnos son ficticios. La creación de reservas en esta demo guarda datos solo durante la visita y verifica disponibilidad de forma básica. No hay backend, cuentas de usuario ni conexión con WhatsApp. La grilla usa franjas visuales de una hora para comparar diseños; la duración real de cada servicio aún requiere reglas funcionales completas.
